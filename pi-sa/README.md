# 点SA库 - π系统

## 两个版本，不同用途

### 1. 点SA版本 (`pi-core-sa.js`) - 锚点系统
**用途**: 定位、标记、索引

**特点**:
- 128字节SA锚点头结构
- 包含锚点ID、时间戳、序列号
- SHA256校验和验证
- 可识别、可验证、不可伪造

**使用场景**:
- 数据标记
- 位置锚定
- 索引生成
- 身份验证

### 2. Go版本 (`pi-core.go`) - 神经网络输入
**用途**: 装进神经网络，做模型测算

**特点**:
- 输出标准化浮点向量 [-1,1]
- 滑动窗口特征提取
- 统计特征扩展
- 批次数据生成

**使用场景**:
- 神经网络训练数据
- 模型输入预处理
- 特征工程
- 实时预测

## 文件结构

| 文件 | 用途 |
|------|------|
| `pi-core-sa.js` | 锚点系统 (Node.js) |
| `pi-core.go` | 神经网络输入 (Go) |
| `pi-daemon.js` | 守护进程 |
| `install-service.bat` | Windows服务安装 |
| `go.mod` | Go模块配置 |

## 快速开始

### 锚点系统
```bash
node pi-core-sa.js
```

### 神经网络数据生成
```bash
go build -o pi-neural.exe pi-core.go
pi-neural.exe
```

## 技术说明

### BBP公式
两个版本都使用BBP公式实时计算π位，确保数据的真实性和不可预测性。

### 数据流
```
π计算 → 特征提取 → [锚点封装] 或 [神经网络标准化]
```
